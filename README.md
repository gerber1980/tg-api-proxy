# Telegram API Proxy

Простой HTTP-прокси, который пересылает запросы с бесплатного хостинга
на `https://api.telegram.org`. Достаточно заменить адрес сервера
`https://api.telegram.org` на адрес хостинга в любом инструменте
(Uptime Kuma, aiogram, python-telegram-bot и т.д.).

## Файлы

- `app.py` — само приложение (Flask + requests).
- `requirements.txt` — зависимости.
- `Procfile` — команда запуска для PaaS-хостингов (gunicorn).

## Защита от сканеров и чужого использования

Прокси отвечает 404 на все пути, кроме рабочих путей Bot API
(`/bot<TOKEN>/метод` и `/file/bot<TOKEN>/...`). Сканеры, стучащиеся в
`/.env`, `/.git` и прочее, ничего не получают, а через прокси нельзя
пользоваться чужими ботами.

### Секретный префикс (рекомендуется)

Задайте на хостинге переменную окружения `SECRET_PATH`, например `my-secret-42`.
Тогда прокси отвечает только на пути вида:

```
https://<хостинг>/my-secret-42/bot<TOKEN>/getMe
```

а корень `/` и любые другие адреса возвращают 404. В инструментах при этом
указывается URL сервера `https://<хостинг>/my-secret-42` — по-прежнему меняется
только адрес.

Без `SECRET_PATH` прокси работает на любом пути `bot.../...`, но его сможет
использовать кто угодно, чей бот он узнает.

## Деплой

1. Загрузите файлы в **приватный** репозиторий на GitHub (токен бота передаётся
   в URL, токен нигде не сохраняется, но приватность — правильная гигиена).
2. На хостинге укажите ссылку на репозиторий: `https://github.com/<user>/<repo>.git`
3. Хостинг сам установит зависимости из `requirements.txt` и запустит процесс
   из `Procfile`. Если старт идёт через Python-скрипт — укажите `app.py`
   (порт берётся из переменной окружения `PORT`).
4. В настройках хостинга добавьте переменную окружения `SECRET_PATH` со
   случайным значением.

## Проверка

Откройте `https://<хостинг>/[<секрет>/]bot123:FAKE/getMe` — должен прийти ответ

```json
{"ok":false,"error_code":401,"description":"Unauthorized"}
```

(401 — потому что токен фейковый; с настоящим токеном вернутся данные бота).
Любой другой путь, включая `/`, отвечает 404.

## Переменные окружения

- `SECRET_PATH` — секретный префикс пути (рекомендуется).
- `TELEGRAM_API_URL` — адрес апстрима (по умолчанию `https://api.telegram.org`).
- `PORT` — порт, обычно задаётся хостингом автоматически.
