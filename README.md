# Telegram API Proxy

Простой HTTP-прокси, который пересылает все запросы с бесплатного хостинга
на `https://api.telegram.org`.

## Файлы

- `app.py` — само приложение (Flask + requests).
- `requirements.txt` — зависимости.
- `Procfile` — команда запуска для PaaS-хостингов (gunicorn).

## Деплой

1. Загрузите файлы в новый репозиторий на GitHub.
2. На хостинге укажите ссылку на репозиторий: `https://github.com/<user>/<repo>.git`
3. Хостинг сам установит зависимости из `requirements.txt` и запустит процесс из `Procfile`.
   Если хостинг стартует не через Procfile, а через Python-скрипт — укажите `app.py`
   (порт берётся из переменной окружения `PORT`).

## Использование

Замените `api.telegram.org` на адрес вашего хостинга:

```
https://<ваш-хостинг>/bot<TOKEN>/getMe
https://<ваш-хостинг>/file/bot<TOKEN>/<file_path>
```

Ваш токен по-прежнему передаётся в пути — хостинг видит его, поэтому репозиторий
должен быть приватным (это не влияет на работу прокси, токен никуда не записывается).

## Переменные окружения (опционально)

- `TELEGRAM_API_URL` — адрес апстрима (по умолчанию `https://api.telegram.org`).
- `PORT` — порт, обычно задаётся хостингом автоматически.
